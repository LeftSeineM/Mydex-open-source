# 内置轻量连接（直连优先，小主机兜底）

目标：使用者不注册 Tailscale、不部署服务器，正常直连不依赖开发者的小主机，无法直连时借助小主机兜底。电脑和手机保留固定配对身份，网络地址变化后重新建立连接。

## 已实现代码

- 安卓电脑下拉框增加删除按钮；离线可删，清除当前连接凭据、会话缓存与重连定时器，不删除电脑上的项目。保留其他设备与字号设置。
- 电脑持久化随机连接身份；二维码包含固定设备标识、电脑证书指纹、一次性兑换码及独立连接访问凭据。手机加密保存配对。
- 同网段 UDP 自动发现，先做固定证书指纹 TLS 验证，不信任广播中的身份声明。
- 无可用局域网路径时使用 WebSocket 字节中继；手机和电脑之间保留原 TLS，模型密钥、网关 Bearer、对话内容不在中继解密。
- 电脑只允许转发到自己网关的 loopback 端口；不能通过中继请求任意地址。连接数量、消息大小和缓冲有上限。
- 电脑主动出站并自动重连；手机沿用连接重试。不会自动重发结果未确认的任务指令。
- 移除 APK 的 Tailscale Go/AAR 运行时依赖。旧 mesh 配对须迁移；直接 IP 配对仍可使用。

## 发布阻塞与真实边界

用户在 2026-11-01 明确接受“直连失败时借助小主机”，并接受小主机离线时在本地重新扫码直连。已部署备用连接服务 /path/to/deployment/projects/mydex-link，SYSTEM 计划任务 Mydex-LightweightLink，监听回环 18084；Cloudflare app 域名仅 /v1 路径转到该服务。它只转发 TLS 字节，不运行 Agent 或模型。手机和电脑无需 Tailscale、VPN、第三方账号。

二维码同时带当前可直连地址和固定设备身份。先验证当前地址与局域网自动发现的证书，直连不可用才使用备用通道。小主机关机时，同一局域网可自动发现或扫码直连；跨网络仍取决于地址可达性，扫码不能绕过网络阻断。

本实现是局域网直连 + 公网端到端 TLS 中继；尚未实现跨 NAT 的互联网 P2P 打洞。跨网络需要可用的中继基础设施；任何方案都不能保证断网、电脑关机或服务不可用时继续连接。

## 运营方部署（使用者不需要操作）

独立公网主机使用 Node 与 gateway/package-lock.json 安装依赖，运行 `gateway/tunnel-server.mjs`，默认仅监听 127.0.0.1:18084。由反向代理提供可信 HTTPS/WSS，转发 `/v1/host/*`、`/v1/connect/*`、`/v1/stream/*`，保留 Upgrade 与 Authorization 头；设置至少 90 秒 WebSocket 空闲超时，限制连接速率。`/health` 仅返回存活状态。

将其 HTTPS origin 写入打包用 `desktop/app-relay.json`，再打包电脑端。用户端只扫码，不需要填写这项。维护者可通过 MYDEX_APP_RELAY 环境变量本地测试；不能用 HTTP 作为发布地址。

中继不保存账户或私人对话，服务重启后电脑自动连接并恢复身份；手机旧流断开后重连。不记录 Authorization、二维码或内容字节。部署应具有资源和连接配额，避免无账号入口耗尽机器资源。

## 已有验证

Node 测试验证不正确凭据被拒绝、TLS 中的内容不可从中继字节读取、主机重连后固定身份仍可用。Flutter 集成测试通过本地 HTTPS 中继完成带鉴权 HTTP GET/POST 和实时 WebSocket，并拒绝错误电脑证书指纹。设备删除测试覆盖离线当前电脑、非当前电脑和保留其他连接。

补充实测：清除测试进程 HTTP_PROXY/HTTPS_PROXY/ALL_PROXY，默认路由为 WLAN、无 Tailscale 出口；真实 Windows 网关通过公网备用通道成功读取设备与 WebSocket 首事件。备用通道设置为不可用时，真实 Windows 网关通过扫码直连地址及 UDP 自动发现均读取成功。手机相机扫码尚未真机验证；Mac 未真机验证。
