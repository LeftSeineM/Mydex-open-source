# 权限模式与底部交互

版本：Android 0.2.12 / Windows 0.4.13 / Mac 测试版 0.5.1-preview.2。

手机会话底部显示桌面返回的权限设置，可手动选择“需要时询问我”“替我审批”“完全访问”“只读”。修改先确认，再发送到当前原会话，必须收到桌面明确确认；用于后续消息，不自动回答已有请求。读取不到状态显示未知，不把“没有审批弹窗”当作完全访问。

“替我审批”使用桌面的自动审批设置并保持工作区沙箱；“完全访问”使用不受文件沙箱限制且不主动请求审批的设置。切换不修改整台电脑或其他会话配置。

待审批、选择题和填空题固定在输入框上方，独立滚动，避免长历史把它们挤到顶部。答案绑定原会话、原请求和原问题 ID；不预选或自动提交。权限申请只批准原请求范围，默认仅本轮有效。回答内容不写入本地会话缓存。

协议依据：本机 Codex app-server 生成的 JSON Schema 与桌面 follower 请求定义。新增测试覆盖权限区分、显式确认、桌面拒绝处理、越界答案、原请求范围、长历史下底部位置和问答提交。真实 Windows 会话只读验证成功；未自动改变用户真实会话权限。Mac 延续用户要求，仅做自动化测试及双架构构建，不做真机联调。
