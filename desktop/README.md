# Mydex 电脑连接器 0.4.23

安装后配置本机 HTTPS 地址，在“配对手机”复制全部信息，在手机添加电脑并粘贴。
每台电脑独立连接，手机保存多组配置并切换。跨网络使用需自己的地址和端口可达。
关闭窗口收起到托盘，退出才停止本应用启动的服务。设置支持用户登录后自启。

工具页区分发现进程、读取历史、新建指令。Claude、ZCode、DeepSeek 安装对应本地兼容桥后可继续原会话；Kimi 连接桌面本地接口，Gemini 连接当前交互进程；详细能力表见根目录 README。

私有配置保存在 data 或导入的原目录，不要公开这些目录。卸载保留 data。
构建见 docs/BUILD.md。脚本向导中保留旧连接模式仅供旧版迁移，当前图形界面使用独立电脑模式。

## Claude 商店版一键接入

在工具接入选择 Claude Desktop，点击安装兼容桥。Mydex 自动发现程序及已有数据目录。WindowsApps 版本在 Mydex 安装目录旁创建可写程序兼容副本，原商店程序不变；安装后自动启动兼容版，沿用已有账号和会话数据，无需填写路径、Token 或模型。先完全退出 Claude；若确实存在多个账号数据目录，仅需选择要使用的账号。可以从 Mydex 重新打开兼容版；直接启动原商店版不会载入本桥。

连接状态以实际原会话接口为准，文件安装成功不代表已接通。商店版本的复制安装与启动参数已通过隔离测试，真实版本的账号和原会话连通仍需用户实测。

## 接入说明与一键恢复

工具页持续显示 Claude 的实际接入方式和副本路径，桥接说明可查看修改范围及能力限制。普通安装使用原地备份加桥，一键恢复只还原匹配的程序备份；商店版使用兼容副本，一键回退删除 Mydex 创建的副本及程序备份，保留原商店程序、原账号配置和聊天记录。退出相关程序后再恢复，不会强行结束任务。

安装副本时可更改存放位置，默认无需修改。删除只处理独立子目录，不删除所选父目录或其他文件；归属不明、未知文件和链接会阻止自动清理。当前实际验证范围为 Code 续聊，Cowork 运行环境及手机接入尚未完成验证。
