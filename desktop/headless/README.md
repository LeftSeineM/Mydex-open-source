# Mydex-agent 0.1.9

Windows x64 / Linux x64 & arm64 / macOS Intel & Apple Silicon. Read skill/SKILL.md before installing. Linux uses systemd --user; macOS uses launchd in the logged-in user session. No sudo, third-party AI SDK or new Coding application. Configuration is retained on update/uninstall.

Linux x64 lifecycle tested under WSL; macOS and ARM builds are previews without real-device end-to-end validation. Original conversation capabilities depend on each tool and its official/existing interface; detection alone is not control. No private Router/Superagent release in these packages.
